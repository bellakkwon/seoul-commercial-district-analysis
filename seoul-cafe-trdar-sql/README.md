# 같은 상권, 다른 성장 신호 — 서울시 상권 데이터 SQL 분석

서울시 공공데이터로 진행한 **독립 SQL 분석 프로젝트**입니다. 특정 기업의 내부 데이터나 실제 영업 성과를 다루지 않습니다.

## 질문
매출 성장률이 높은 상권이 신규 가맹점 영업에도 유리할까?
가상의 오프라인 결제 서비스 영업팀이 한정된 현장 조사 리소스를 어느 상권에 먼저 배분할지 정하는 상황을 가정했습니다.

## 분석 흐름
1. **데이터 검증** — 키 중복·NULL, 2025년 점포 파일의 영문 컬럼명 통일, 점포 수 분모 확인(`점포_수`는 프랜차이즈 제외값 → `유사_업종_점포_수` 사용), 매출 누락 상권 프로파일
2. **가설 재검토** — 총매출 성장률 TOP 20과 점포당 매출 성장률 TOP 20 비교 → KPI 분해(총매출 = 점포 수 × 점포당 거래건수 × 거래당 매출)
3. **의사결정 기준** — 개업 3곳 이상, 개업 > 폐업, 연간 점포당 거래건수 증가, 분기 지속성(4개 분기 중 3개 이상)으로 조사 후보 20곳 선정
4. **후속 검증** — 상권변화지표와 실제 카페 위치(공간 결합)로 후보 20곳에 현장 확인 항목 추가

## 주요 결과 (커피-음료, 분석 대상 555개 상권, 2024→2025 연간)
| 항목 | 결과 |
|---|---|
| 총매출 vs 점포당 매출 TOP 20 중복 | 15/20 (순위 상관 0.86) → 초기 가설 미지지 |
| 점포당 매출 +1.3% 분해 | 점포당 거래건수 −0.03% × 거래당 매출 +1.4% |
| 매출 증가 상권 중 점포당 거래건수 감소 | 67/214곳 (31.3%) |
| 분모 정의 영향 | 프랜차이즈 제외 점포 수를 쓰면 48곳의 점포당 거래건수 증감 방향이 달라짐 |
| 새 기준 후보 20곳 vs 연간 총매출 TOP 20 | 2곳만 중복 |
| 후속 검증 | 상권축소 3곳, 유형 내 카페 밀도 상위 25% 8곳 → 11곳에 현장 확인 항목 추가 |
| 점포 수 집계 비교 | 소진공 카페 수 vs 서울시 커피 점포 수 상관계수 0.984 |

## 실행 방법
```bash
pip install duckdb geopandas pyogrio pandas
# 1) data/raw/에 원천 파일 넣기 (data/README.md)
python python/prepare_data.py        # UTF-8 변환, SQL이 읽는 파일명으로 저장
python python/spatial_cafe_join.py   # 카페 위치 × 상권 경계 공간 결합
python python/run_sql.py             # SQL 전체 실행, 섹션별 결과 출력
```

## 한계
- 추정매출은 카드사 데이터 기반 추정치이며, 업종·상권 평균입니다.
- 점포가 있는데 매출 행이 없는 커피 상권(2025Q4 29.5%)은 제외했습니다. 점포 비중은 6.1%지만 골목상권·전통시장의 소규모 상권에 집중돼 선택 편향 가능성이 있습니다.
- 카페 위치(2026.09)와 거래 데이터(2025)의 시점이 다르고, 상권변화지표는 전 업종 기준입니다.
- 후보 선정은 현장 조사 우선순위를 정하는 시뮬레이션이며, 계약 전환율 같은 실제 영업 성과로 검증하지 않았습니다.
